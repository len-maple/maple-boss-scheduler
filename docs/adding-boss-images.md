# ボス画像の追加方法

ボスの公式アートワークはNexonの著作物のため、このリポジトリには画像ファイルを含めていません。
以下の手順で、お使いの環境に自分で画像を追加してください。

1. 用意した画像ファイルを `public/bosses/` に置く
   - ファイル名は [src/bosses.ts](../src/bosses.ts) の `image` に書いた名前と一致させる
   - 例: `public/bosses/zakum.png`
2. `src/bosses.ts` の `BOSS_LIST` を編集し、実際にパーティーで周回するボスの一覧に合わせる
   - `id`: 内部的な識別子（英数字、他と重複しないもの）
   - `name`: 画面に表示するボス名
   - `image`: `public/bosses/` 以下のパス
3. 画像が見つからない場合は自動的にボス名の頭文字を表示するプレースホルダーになるので、
   画像がまだ無いボスがあっても動作は壊れません。
